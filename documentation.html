Email System Integration

The Manisha-A portal now supports a localized Node.js email backend. To activate:

  1. Navigate to the /backend directory.
  2. Configure your credentials in the .env file.
  3. Run npm start to initialize the transmission server.
  4. Test the connection via email_test.html.
